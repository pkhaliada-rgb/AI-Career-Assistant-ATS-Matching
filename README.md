## Overview

An AI-powered career support platform for comparing resumes with job descriptions, calculating ATS-style match scores, identifying missing skills, customizing resume content, generating cover-letter drafts, and tracking job applications.

## Key Features

- Resume-to-job-description matching
- ATS-style scoring
- Skill extraction and missing-skill detection
- Resume customization suggestions
- AI-assisted cover-letter drafting
- Job application tracking
- Career content ideas
- CSV/report export
- Streamlit dashboard

## Running the Project

Install the dependencies:

```bash
pip install -r requirements.txt
```

If model training is included in the project, run the available training script from the `src` directory before launching the dashboard.

To launch the Streamlit application:

```bash
streamlit run app/app.py
```
